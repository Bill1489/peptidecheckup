PEPTIDE COMPARE — LOGO KIT
==========================

Files
  compare-peptide-logo-horizontal(.svg/.png)            Primary lockup — mark + wordmark, ink + cobalt, transparent background
  compare-peptide-logo-horizontal-reversed              White + light cobalt on ink (for dark backgrounds / video)
  compare-peptide-logo-horizontal-mono                  Single-colour ink (print, embossing, one-colour contexts)
  compare-peptide-logo-horizontal-mono-white            Single-colour white (over photography)
  compare-peptide-logo-stacked(-reversed)               Centred lockup for square-ish spaces
  compare-peptide-wordmark(-reversed)                   Wordmark alone
  compare-peptide-mark / -mono / -white                 The chain mark alone, transparent
  compare-peptide-app-icon / -cobalt                    1024 px square app / avatar icons (ink and cobalt)
  favicon.svg                                           Browser tab icon
  preview-sheet.png                                     Overview

All SVGs are pure vector (text converted to outlines) — scale to any size, open in Figma / Illustrator / Canva.
PNGs are exported at 4096 px wide (lockups), 2048 px (marks) and 1024 px (icons) with transparent backgrounds
except the "reversed" and app-icon files.

Colours
  Ink          #0B0B0C   (not pure black)
  Cobalt       #1D3BFF   (terminal residue, "PEPTIDE")
  Light cobalt #8FA1FF   (cobalt on dark backgrounds)
  White        #FFFFFF
  Paper        #F4F3F0   (preferred warm off-white background)

Type
  Wordmark: Archivo, weight 800, width 112 (semi-expanded), all caps, letter-spacing −0.01 em.
  Google Fonts: https://fonts.google.com/specimen/Archivo  (variable font — use the "wdth" axis at 112)
  Supporting mono: IBM Plex Mono.

The mark
  Four square residues on a zig-zag peptide backbone; the terminal residue is cobalt — the one the Checkup lands on.
  Keep square caps and mitred joins; never round, outline, rotate or recolour the mark beyond the versions here.

Clear space & minimum size
  Clear space all round: the height of one residue square (the small square in the mark).
  Minimum size: lockup 120 px / 30 mm wide; mark alone 16 px.
